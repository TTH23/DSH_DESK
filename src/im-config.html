QQ 机器人配置

在 QQ 开放平台（q.qq.com）创建机器人应用后获取；程序用 AppID+AppSecret 自动换取 access_token。
白名单可选；未命中时只通知主机不回复。官方模式的「服务器 IP 白名单」与 WebSocket 模式无关，不用填。
go-cqhttp / NapCat / LLOneBot 的 WebSocket 服务地址（正向 WS）
白名单至少填一项，否则机器人不会启动（安全必需）。
频道无对话超过该时长自动清空工作区/会话绑定，下次需重新选择。填 0 = 不自动退出。
在软件（非 QQ）里发起的任务完成后，是否通过 QQ 推送结果：全文 / 只发完成提醒 / 不推。
设置后，频道首次发送口令才能解锁对话。
